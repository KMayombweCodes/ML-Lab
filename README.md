# ML Projecs
*My projects, notes and learning journey* 

This repository documents my personal development in Machine Learning and Data Science, including weekly assignments, experiments, notes and projects.

I aim to build a strong theoretical foundation and practical skills by applying ML concepts to real-world datasets using Python and widely used DS libraries.


## Contents

The *repo* is organised by week (the actual week in which I "commit" each piece of work) or by topic as I progress:

### Week 1 — Regression and Classification

The first week focused on building a complete machine learning workflow using a housing dataset containing deliberate data-quality issues.

Topics covered:

- Data inspection and understanding

- Data cleaning and preprocessing

- Handling missing values

- Handling malformed numerical values

- Categorical data cleaning

- Duplicate detection and removal

- Exploratory Data Analysis (EDA)

- Correlation analysis

- Train/test splitting

- Data leakage

- Feature preprocessing

- One-hot encoding

- Feature scaling

- Pipelines

- Linear Regression

- Logistic Regression

- Model evaluation

Models and metrics included `LinearRegression`, Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), $R^2$, `LogisticRegression`, Accuracy, Precision, Recall, $F1$ score, and the Confusion matrix.

The week also covered model interpretation, feature importance, limitations and possible improvements such as feature engineering and non-linear models.

### Week 2 — Decision Trees and Random Forests

The second week builds on the regression and classification concepts introduced in Week 1.

Topics include:

- Decision Trees

- Random Forests

- Tree-based classification and regression

- Model training and evaluation

- Feature importance

- Overfitting and generalisation

- Comparing tree-based models with simpler baseline models

- Model interpretation

- Practical ML questions and perspectives 

Further topics and weekly assignments will be added as I progress through the learning journey.
